Connectivity

Network

Ethernet (PoE) is always on. Wi-Fi can run alongside it. Art-Net and this page are reachable on both. Saving network settings restarts the device.

⚠The setup hotspot is on because no network was available. It closes 2 minutes after Ethernet or Wi-Fi connects.

About
Inputs
USB audio

Plays sound effects through a USB speaker on the USB-C port. While on, that port can't be used for the serial monitor. Changing this restarts the device.

Firmware update

Upload a firmware.bin built from this project. The device restarts when the upload finishes; settings are kept.

Maintenance

Factory reset erases every setting, including Wi-Fi and static IPs. You can also hold the BOOT button for 5 seconds.
